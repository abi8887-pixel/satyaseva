Welcome to the photo folder for SCS Bydgosh Community!

HOW TO ADD PHOTOS (NO CODING NEEDED):
1. Copy or drop your pictures (.jpg, .jpeg, .png, .webp) directly into this folder.
2. (Optional) If you want a specific picture to be the top banner / header photo on the website, rename it to:
   hero.jpg   (or hero.png)
3. All other photos placed in this folder will automatically appear in this community's gallery!

That's all! The website updates automatically.
